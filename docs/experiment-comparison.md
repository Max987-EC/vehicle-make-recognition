# 論文設定與本次實作對照

本次屬於「使用替代資料重現論文方法」。補充設定於 2026-10-26 經使用者確認。

| 項目 | 論文設定 | 本次實際設定 | 差異原因 |
|---|---|---|---|
| 資料 | 作者收集之白天車頭圖片 | CompCars surveillance，逐圖審查白天外觀 | 未找到可取得的原始資料 |
| 品牌 | Toyota、Honda、Mazda、Nissan、Isuzu | 前四者與 Volkswagen | 官方 surveillance 標籤無 Isuzu，依有效數量備援 |
| 數量 | 5 類，每類 200 張 | 相同 | — |
| 切分 | 固定種子打亂，80/20 | seed 42，800/200，三模型共用清單 | 原種子未公開；非分層切分 |
| 輸入 | 244×244 RGB | 相同；bilinear，像素除以 255 | 插值與正規化未公開 |
| 區塊 | 六層、GAP、Dense 256、五類 | 相同；通道 32/64/128/256/512/1024 | 依偽程式碼修正文內漏列 256 |
| DR 降維 | 正文固定 16，圖示 X/2 | 固定 16 | 與正文及表 3 參數量一致 |
| BN | 使用 BN，完整設定未公開 | beta、無 gamma，eps .001、retention .99 | 可對齊參數量的推定，非作者程式證據 |
| 訓練 | 從頭訓練、Adam、200 epochs | 相同；LR .001、batch 32 | 未公開值採已確認補充設定 |
| 評估權重 | 訓練 200 epochs | 第 200 epoch | 不以測試分數選模 |
| 框架 | TensorFlow 2.10 | PyTorch 2.7.1+cu128 | 使用者指定；Adam 等數值細節非逐步等價 |
| 硬體 | RTX 3060 Ti | RTX 4060 Laptop GPU | 使用既有電腦，速度不直接與作者比較 |
| 推論 | 200 張，8 組×25 | 相同；另加 3 組暖機及 GPU 同步 | 原暖機與同步細節未公開 |

完整補充值見 [assumptions.md](assumptions.md)，來源查核見 [source-audit.md](source-audit.md)。正式成績由 [comparison.md](../outputs/comparison.md) 彙整；未完成訓練前不填入推估成績。

資料限制：白天為視覺外觀判定，沒有拍攝時間真值；亮度候選門檻可能排除較暗白天圖。已排除相同解碼像素，未保證同車不同影格或近似影像跨切分分離。本次只使用一個種子，不能由單次結果推論跨資料集表現。
